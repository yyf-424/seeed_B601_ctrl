# v0.4.0 上层框架验收

适用工作区 `codex/varstiff-target-arbitration`。MIT 控制器沿用主线 `3d4efa5` 的实现和配置。

## 节点和数据流

| 接口 | 职责 |
|---|---|
| `scripts/start_target_web.sh` | 启动本地网页及命名空间 `/b601_preview` 下的模型发布器。独立启动时展示默认姿态。重复执行返回已有控制台地址 |
| `b601_target_web` | 展示 URDF、实测和目标姿态。支持 TCP 位置逆解、七关节草稿、控制权操作、运行后端选择、归中与 Disable |
| `b601_target_arbiter` | 整机只授予一个有效会话。确认会话、递增序号、有限值及关节限位后，向手臂和夹爪分别发布授权目标 |
| `b601_target_bridge` | 调用现有 MIT 控制器的 `joint_target` 入口，按控制器消费序号匹配回执。来源失联或仲裁心跳中断时，以新鲜实测位置提交持位目标 |
| `b601_mit_recenter` | 通过整机仲裁接管，按 J4 上抬、其余五轴归中、J4 回落执行，依据六轴实测及控制器回执完成归中 |

网页、外部策略和命令行客户端共用 `TargetFrame`。整帧包含六个手臂关节和主动夹爪，速度可选。控制器的采纳回执用于确认目标已经消费，位置误差和到位窗口用于确认运动完成。网页 Disable 需要最近一次归中回执及六轴仍在停放范围。执行期间仲裁会冻结新的会话申请，网页确认硬件进入 `inactive` 后退出后端。

## 已验证行为

| 场景 | 验收结果 |
|---|---|
| 独立网页和模型发布 | 浏览器显示默认姿态。ROS 图只有网页和预览模型发布器。预览 URDF 有 11 个链节，根话题 `/joint_states` 无发布者 |
| 网页启动的重复调用 | 已有预览时复用同一进程。普通 HTTP 服务占用端口时启动命令报告冲突并保留原服务 |
| 默认 MuJoCo | 网页手动连接后收到运行时模型及关节反馈，归中与 Disable 后恢复静态预览。既有浏览器验证覆盖 TCP 草稿、手动发送及整机回执 |
| ROS 目标仲裁 | 验证整机会话争用、完整目标、重复帧拒绝、两路采纳、外部策略交接、归中与失能预约、撤销、来源断流持位和仲裁重连 |
| 重力与碰撞 | MuJoCo 默认 `free`。`physical` 同时开启重力和碰撞并使用同一组关节限位。开启后曾观测到 `link1` 与 `link3` 接触，标定归中超时 |

TCP 网页逆解使用关节指令范围和位置残差。带碰撞检查的 MoveIt 规划走独立路径。历史实机记录覆盖部分网页连接、刚度回读及停机链路，本版发布验收在离线和隔离 MuJoCo 中执行。

2026-11-25 发布复测构建 10 包，自检 33/33，安全矩阵 81/81，隔离 MuJoCo 仲裁回归 7 组通过。本轮分别在 0.638 s 和 0.599 s 观察到来源断流和仲裁中断后的持位回执。独立 HTTP 回归覆盖预览复用、运行时模型切换、七关节目标采纳、归中失能和预览恢复。

夹爪两指在常规档和低刚度档的实测超速急停阈值为 `0.25 m/s`，警告线为 `0.20 m/s`。常规档超过阈值触发，低刚度档达到阈值即触发。隔离 MuJoCo 的安全节点已回读两档新值。夹爪命令速度上限为 `0.05 m/s`。

## 待验收的上层流程

| 流程 | 当前证据 |
|---|---|
| v0.4.0 实机发令和控制权交接 | 新版尚无从 TCP 草稿或七关节目标提交到实测到位的完整记录。外部策略或命令行与网页切换、来源断流持位的系统验收来自 MuJoCo |
| v0.4.0 实机网页归中、Disable、恢复预览 | 历史记录覆盖网页连接、单次目标采纳、归中反馈及按标准 ROS 服务失能。当前网页管理的整条停机与后端切换流程已用 MuJoCo 验证，待在新版实机复测 |
| MuJoCo `physical` 归中失能 | 已试验。现有模型的 `link1` 与 `link3` 接触使归中超时，因此尚未走到正常 Disable 和恢复预览 |
| 开启 MoveIt 碰撞检查的网页归中 | 当前发布回归走默认归中配置。显式打开碰撞检查后，从网页归中到 Disable 的端到端流程待验收 |
| 上层其他故障与恢复 | 已覆盖指令来源超时和仲裁进程暂停。转发节点退出、反馈中断、网页服务意外退出后接回原后端，以及多轮启停的稳定性，均缺少本版验收记录 |

## 复测

从工作区根目录构建并运行静态校验和隔离仲裁回归。

```bash
./scripts/build.sh
./scripts/verify.sh
source ros2_ws/install/setup.bash
python3 scripts/test_target_arbitration.py
```

默认回归使用 ROS 域 `227`。可以用 `B601_TEST_ROS_DOMAIN_ID` 指定另一个空闲域。独立网页复测使用 [启动脚本](../scripts/start_target_web.sh)，打开 [控制台](http://127.0.0.1:8765/)，依次观察默认姿态、手动连接 MuJoCo、归中、Disable 和预览恢复。支持 `port:=8766` 指定独立端口。
